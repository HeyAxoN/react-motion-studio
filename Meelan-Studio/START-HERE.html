Install on Windows

  1. Extract the entire ZIP.
    Close After Effects before continuing.
  2. Run Install-Windows.cmd.
    Read the notice and type INSTALL.
  3. Enable file access in AE.
    Preferences → Scripting & Expressions → Allow Scripts to Write Files and Access Network.
  4. Open your panel.
    Window → Extensions → Meelan Studio. Dock it beside your timeline.
This build is an unsigned CEP extension. Its installer enables Adobe's developer loading setting for your user account and records the previous value. It does not require administrator access. Your existing composition collection stays in place.

macOS: Run Install-macOS.command after extracting the ZIP and closing AE. If needed, run it using bash in Terminal.

Check the first scene

Start a new AE project. From File → Scripts → Run Script File, run tools/Create-AE-Test-Scenes.jsx. This optional utility creates sample scenes and writes a response report to your Desktop. Preview them, then use the panel to test a Store round-trip.

Release candidate, not desktop-certified.
Preview playback, settings and code checks have been checked locally. Actual AE rendering, model import and installer execution still need testing on Windows/macOS. Complete the included acceptance checks before giving this build to students.
