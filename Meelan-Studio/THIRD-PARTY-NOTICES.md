# Components and references

The runtime payload contains original Meelan Studio code, preview artwork and three original GLB cursor models under the MIT license. No commercial aescripts product, third-party model weights, or inference runtime is bundled in this revision.

Development-only npm dependencies are not included in the installable payload. Acorn and Playwright are used for checks under their respective upstream licenses.

Implementation references:

- [Adobe CEP resources](https://github.com/Adobe-CEP/CEP-Resources): runtime, manifests and installation.
- [Adobe model import guide](https://helpx.adobe.com/after-effects/desktop/import-files/import-and-add-3d-models/import-3d-model.html): native GLB import and Advanced 3D.
- [After Effects scripting reference](https://ae-scripting.docsforadobe.dev/): project and property operations.
- EXPANSION-REVIEW.md: product references and OpenAI documentation for proposed additions. No proposed integration is bundled.
